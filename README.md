## ☁️ Google Sheets — Clientes

1. Crie uma planilha chamada **ProspectFlow Clientes**
2. Abra **Extensões → Apps Script**
3. Cole o conteúdo do arquivo `google-apps-script.js`
4. Implante como **App da Web → Qualquer pessoa**
