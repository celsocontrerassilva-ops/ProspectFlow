# ⚡ ProspectFlow

Sistema completo de CRM e prospecção inteligente para qualquer segmento B2B.

-----

## 🚀 Como usar

1. Crie um repositório no GitHub chamado `prospectflow`
1. Faça upload de todos os arquivos
1. Ative o **GitHub Pages** em Settings → Pages → Branch: main
1. Acesse: `https://SEU_USUARIO.github.io/prospectflow`

-----

## 🔐 Login padrão

- 👤 Usuário: `admin`
- 🔒 Senha: `prospect2026`

-----

## ☁️ Banco de dados (Google Sheets)

1. Acesse **sheets.google.com** e crie uma planilha chamada `ProspectFlow`
1. Abra **Extensões → Apps Script**
1. Cole o conteúdo do arquivo `google-apps-script.js`
1. Implante como **App da Web** → Qualquer pessoa
1. Cole a URL em **⚙️ Configurações**

-----

## 📱 Funcionalidades

- 🏠 Dashboard com temperatura da carteira
- 🎯 30 contatos sugeridos por dia
- 👥 Gestão completa de clientes
- 🏆 Ranking de melhores clientes
- 🤖 Automação de mensagens WhatsApp
- 📊 Relatórios diário/semanal/mensal
- 🌤️ Disparo para clientes Mornos
- 🔍 Detector de duplicatas
- 📥 Importação via CSV/Excel

-----

## 🔑 Dados importantes

- **Evolution API:** configure em Automação → Conexão WhatsApp
- **Instância WhatsApp:** crie em https://seu-servidor/manager
